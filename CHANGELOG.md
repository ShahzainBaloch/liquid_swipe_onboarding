## 1.0.0

* Initial release of `liquid_swipe_onboarding`.
* Touch-anchored fluid cubic Bézier wave clipping path.
* Two-way interactive drag transitions with spring physics.
* `LiquidSwipeController` for programmatic navigation (`nextPage()`, `previousPage()`, `animateToPage()`).
* Built-in morphing pill & dot indicator (`LiquidPageIndicator`).
* Zero external dependencies, 100% Impeller rendering compatible.
